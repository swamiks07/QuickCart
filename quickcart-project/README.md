# 🛒 QuickCart – E-Commerce Web Application

  QuickCart is a React-based e-commerce web application that provides a simple and interactive online shopping experience. Users can browse products, search for items, manage their shopping cart, select delivery options, place orders, view order history, and track their orders.

The project focuses on building a dynamic shopping experience using React components, API integration, and a clean user interface.

---

## 🌟 Key Features

### 1. 🏠 Home Page – Product Listing

- Displays a collection of products with images, names, prices, and customer ratings.
- Search functionality to find products.
- Select product quantities before adding them to the cart.
- Add products to the shopping cart.
- Navigation to Orders and Cart pages.
- Dynamic cart item count displayed in the navigation bar.

### 2. 🛒 Cart & Checkout Page

- Displays all products added to the shopping cart.
- View product details, prices, and quantities.
- Remove products from the cart.
- Choose from multiple delivery options.
- View estimated delivery dates and shipping charges.
- Automatically calculates:
  - Items subtotal
  - Shipping and handling charges
  - Estimated tax (10%)
  - Final order total
- Place an order through the checkout interface.

### 3. 📦 Orders Page

- Displays previously placed orders.
- Shows order details, including:
  - Order placement date
  - Unique Order ID
  - Total order amount
  - Ordered products
  - Product quantities
  - Expected arrival dates
- Track individual packages.
- Add previously ordered products to the shopping cart.

### 4. 🚚 Track Order Page

- Track individual products from the Orders page.
- Displays the expected delivery date.
- Shows product information and quantity.
- Provides a visual order-tracking progress indicator with three stages:
  - **Preparing** – Order is being prepared.
  - **Shipped** – Order has been dispatched.
  - **Delivered** – Order has reached its destination.
